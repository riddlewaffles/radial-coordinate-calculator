# Radial Coordinate Calculator (RCC)
#### A lightweight tool designed to compute 2D Cartesian coordinates $(x, y)$ for points positioned evenly along a circle. Useful for 2D/3D graphics development, animation planning, geometry problems, or circular object placement in design.
#### Given a radius $r$ and a specific number of points $d$, the program evenly divides $360^\circ$ to calculate the angle and exact $(x, y)$ position for each point. Automatically handles floating-point math inaccuracies so coordinates near zero display cleanly (e.g., as 0.0000 rather than long floating-point decimals).
